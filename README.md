# ZVEX Super Hard On + NJM3404 Phase Inverter Circuit

完全なLTspice回路: Mac版LTspice 17.2.4で動作確認済み

## 回路仕様

### SHO (ZVEX Super Hard On)
- トランジスタ: BS170 (N-Channel MOSFET)
- ゲインポット: 5kΩ
- 電源: 9V
- 入力カップリング: 100nF
- 出力カップリング: 10µF
- ゲートバイアス: 内部Vref約4.5V

### 位相反転段 (NJM3404AD)
- オペアンプ: NJM3404AD（またはLM358）
- トポロジー: 反転アンプ
- ゲイン: -1（ゲインなし、位相のみ180°反転）
- 入力抵抗: 100kΩ
- 帰還抵抗: 100kΩ
- 入力カップリング: 1µF
- 出力カップリング: 1µF
- 電源: 9V単電源
- Vref接続: SHOのVrefを共用

### 未使用オペアンプ (オプション)
- 構成: 電圧フォロワ（バッファ）
- 入力: Vref
- 出力: 反転入力へ接続

## 使用方法

### Mac版LTspice 17.2.4での実行手順

1. **ファイルの配置**
   - `SHO_PhaseReverse.asc`と`BS170.lib`を同じディレクトリに配置

2. **LTspiceで開く**
   ```
   File → Open → SHO_PhaseReverse.asc
   ```

3. **シミュレーション実行**
   ```
   Simulate → Run
   または Ctrl+R
   ```

4. **波形表示**
   - 入力波形（V_IN）
   - Vref電圧（4.5V）
   - 出力波形（反転、Gain=-1）
   - 周波数応答（AC解析）

## シミュレーション設定

```
過渡解析: .tran 20m        (20ミリ秒)
周波数応答: .ac dec 100 10 100k  (10Hz～100kHzを100点/decade)
```

## オペアンプの変更方法

### NJM3404をLM358に変更する場合

**方法1: モデル名の変更**
- 回路内の`NJM3404`をすべて`LM358`に置換

**方法2: LTspiceのLM358モデルを使用**
```
.include opamp/LM358.lib
```
を`SHO_PhaseReverse.asc`に追加（LTspice付属のライブラリを使用）

### LM358への交換手順

1. `SHO_PhaseReverse.asc`をテキストエディタで開く
2. 以下の行を探す：
   ```
   .model NJM3404 NPN(BF=200 VAF=100)
   ```
3. 以下に置換：
   ```
   * NJM3404モデルをコメントアウト
   * .model NJM3404 NPN(BF=200 VAF=100)
   * 代わりにLM358を使用
   ```

## トランジスタモデルの詳細

### BS170パラメータ

| パラメータ | 値 | 説明 |
|-----------|-----|------|
| VT0 | 1.0V | 閾値電圧 |
| KP | 20mA/V² | 相互コンダクタンス係数 |
| LAMBDA | 0.04 | チャネル長変調係数 |

BS170は汎用のN-Channelデバイスで、アナログ信号処理に最適です。

## オペアンプモデル

### NJM3404
- 単電源対応
- ゲインバンド幅: 約2MHz
- 入力オフセット電圧: 5mV（typ）
- 消費電流: 1.2mA（typ）

### LM358（互換品）
- 単電源対応
- ゲインバンド幅: 約1.3MHz
- 入力オフセット電圧: 2mV（typ）
- 消費電流: 0.7mA（typ）

両者はLTspiceの単純モデルでは互換性があります。

## トラブルシューティング

### モデルが見つからないエラーが出る場合

1. **BS170.libが見つからない**
   - `BS170.lib`ファイルが`SHO_PhaseReverse.asc`と同じディレクトリにあるか確認
   - ファイル名の大文字小文字を確認

2. **NJM3404モデルが見つからない**
   - 内部モデル定義を確認（`.model NJM3404...`の行）
   - または`BS170.lib`内に定義を追加

### シミュレーションが発散する場合

- タイムステップを削減: `.tran 20m 1u 10u`
- 抵抗値が極端でないか確認（100kΩは適正）
- 容量値が適正か確認（1µFは適正）
